Console commands relevant to Auto Raid
Source: strings embedded in C:\CK3\binaries\ck3.exe (console_command_implementation.cpp).
`help`/`helplog` did not write output to any log in this version (tested 2026-10-03).

Movement
- instamove      "Instant army movement" (speed cheat, does not give an order)
- quickmove      "units and travels move one province each day" (speed cheat)
- verify_ai_path "Verify an AI unit's path" (debug)
No march order command.

AI
- set_is_ai      "Set a character to be controlled by an AI" (whole character)
- AI.Enable      "enables the AI of a character"
- AI.Disable     "disables the AI of a character"
- AI.ToggleAll / AI.Toggle*  turn AI modules on/off (global)
- aiwatch, ai_war_coordinator_watch  AI debug windows

Script
- effect {effect script}   runs an effect (root = played character)
- trigger {trigger script} tests a trigger
- script_docs              generates effects.log, triggers.log, on_actions.log, event_targets.log in logs\

Other
- move_unit is NOT a console command: it is the internal network command type generated by the player's click
  (shows up in logs\message.log as "Type: move_unit"). Typing it in the console: unknown command.
